# Public-page evidence walkthroughs

Three short demonstrations capture factual public pages and route each task to its matching owned destination. Each package contains one silent MP4, source screenshots, publishing metadata and ten selectable caption files.

| Package | User task | Owned destination |
|---|---|---|
| [Vnish Global catalog correspondence](global-build-verification/) | Resolve the catalog record and compare local SHA-256 | <https://vnish.global/data/> |
| [VNISH Ninja recovery route](ninja-recovery-route/) | Check recovery inputs and stop conditions | <https://vnish.ninja/recovery/> |
| [ROI ASIC staged fleet baseline](roiasic-fleet-baseline/) | Move from one device to bounded waves with rollback gates | <https://roiasic.com/enterprise/> |

The videos use captures of public pages and editorial text overlays. They do not depict a successful flash, measured performance or profitability. The ten captions are translations of the same bounded demonstration, not separate claims.
