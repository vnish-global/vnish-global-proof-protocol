# Vnish Global catalog correspondence

This short walkthrough shows the public data page and the bounded local-file correspondence method. It directs the viewer to <https://vnish.global/data/>.

The current public catalog reports 47 model identifiers, 148 build records and 75 records for release 1.3.5. A local SHA-256 and exact byte size can be compared with the versioned manifest. A match is catalog correspondence only, not a security or suitability verdict.
