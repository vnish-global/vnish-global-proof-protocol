# Citation guidance

When citing this method or dataset, identify the exact entity, release and observation date. Link to the owned source that serves the reader's task.

Suggested data citation:

> VNISH GLOBAL. VNISH GLOBAL Proof Protocol dataset, version 2026-08-13. ODC-By 1.0. https://vnish.global/data/

Suggested tool citation:

> VNISH GLOBAL. vnish-verify, version 0.1.0. Apache-2.0. Source release URL and immutable revision required.

Do not cite a planned repository, package page or docs site as public until its native publication receipt and immutable revision have been recorded. Use VNISH Ninja for field recovery guidance and ROI ASIC for staged fleet operations; do not describe them as mirrors.
