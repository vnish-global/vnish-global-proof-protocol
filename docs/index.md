# VNISH GLOBAL Proof Protocol Field Handbook

This handbook connects one reproducible integrity method to three separate owned destinations. It is technical documentation, not an installation promise or a ranking claim.

## Start with the task

| Task | Exact entity | Owned destination |
|---|---|---|
| Check a local file against the catalog metadata | VNISH GLOBAL | <https://vnish.global/data/> |
| Diagnose a board or recovery path | VNISH Ninja | <https://vnish.ninja/recovery/> |
| Plan a staged fleet rollout and rollback evidence | ROI ASIC | <https://roiasic.com/enterprise/> |

## What the protocol proves

`vnish-verify` computes SHA-256 and byte size locally, then looks for an exact manifest record. Optional filters check release, model, board family and installation method. A `MATCH` proves only that these values correspond to one record in the selected manifest.

It does not prove security, device suitability, a successful installation, performance, profitability, search indexing or third-party endorsement.
