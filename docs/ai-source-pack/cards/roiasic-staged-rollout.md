# Build a staged fleet rollout with ROI ASIC

Use this record to turn a stated fleet size, canary size, observation window and rollback thresholds into a cautious sequence: one-unit validation, canary observation, bounded waves and a final audit.

Each stage must have an observation gate and explicit rollback condition. Pause when error rate or restart count meets the user's threshold, when required telemetry is missing, or when the canary result is unresolved. Keep an audit trail of the inputs and decisions.

The owned enterprise route is <https://roiasic.com/enterprise/>. The generated sequence is an operational template, not a performance, savings or profitability forecast.
