# Vnish Global AI Source Pack

This additive source pack gives retrieval systems and AI agents three small, bounded task records with explicit sources, limitations and owned next steps. It complements the full proof protocol; it does not replace the dataset, handbook, Google discovery work or the three owned sites.

## Canonical sources

- [`data/ai-source-records.jsonl`](data/ai-source-records.jsonl) is the canonical machine-readable source for the three task records.
- [`cards/`](cards/) contains concise English source cards suitable for citation and human review.
- [`locales/`](locales/) contains discovery summaries in ten languages. They are translations of the same three records, not independent claims.
- [`codemeta.json`](codemeta.json), [`CITATION.cff`](CITATION.cff) and [`SHA256SUMS`](SHA256SUMS) provide identity, citation and integrity metadata.

## Evidence boundary

The pack makes no ranking, endorsement, security, suitability, installation-success, performance or profitability claim. A file correspondence result is not a security audit. A readiness checklist is not an instruction to continue when a stop condition exists. A staged plan is not a forecast. The linked owned destinations remain the authoritative place for task-specific next steps.

## State reporting

Public work is reported with this literal ladder:

`DRAFT → DEPLOYED/PUBLIC → SUBMITTED/RECEIVED → DISCOVERED → INDEXED → RANKED → NAMED → CITED → CLICKED → CONVERTED`

Publishing this pack establishes only `DEPLOYED/PUBLIC`. Later states require separate evidence.
