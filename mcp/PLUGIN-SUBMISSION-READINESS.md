# Plugin submission readiness

The code and public documentation supply the technical pieces needed for client testing: a Streamable HTTP MCP endpoint, narrow read-only tools, starter prompts, privacy notice, terms and support route.

Public ChatGPT plugin submission is a separate state. It requires an eligible OpenAI Platform organization, Apps Management Write access, completed developer or business identity verification, listing metadata, tool tests and policy attestations. No submission or approval is claimed by this repository.

Claude custom-connector installation is also a separate client-side state. A deployed endpoint can be tested without claiming directory discovery, review or endorsement.

Use the literal evidence ladder for each client:

`DRAFT → DEPLOYED/PUBLIC → SUBMITTED/RECEIVED → DISCOVERED → INDEXED → RANKED → NAMED → CITED → CLICKED → CONVERTED`
