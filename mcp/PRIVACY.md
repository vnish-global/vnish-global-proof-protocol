# Privacy notice

Publisher: Vnish Global.

The public MCP tools require no account, cookies or personal information. Inputs are used only to calculate the response to the current request. The Worker has no application database, analytics integration or persistent user-data storage, and Worker observability is disabled in the deployment configuration.

Do not submit secrets, personal information or firmware binaries. The correspondence tool accepts only caller-computed metadata such as SHA-256, byte size and optional catalog filters.
